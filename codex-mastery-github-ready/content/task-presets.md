## 中文网站开发

**标签:**

- Next.js
- 页面
- 响应式

**预设内容:**

**角色:** 你是一名前端架构师、产品经理和 Apple 风格视觉设计师。

**目标:** 在现有 Next.js 项目中实现一个中文资源中心页面，帮助中国用户快速找到可复制的工作模板。

**上下文:** 项目使用 Next.js App Router、React、TypeScript 和 TailwindCSS。内容来自本地 data/*.json。现有页面已经有深色模式、导航和卡片组件。

**限制条件:** 保持中文主体；不引入新的 UI 框架；不修改无关页面；移动端不能出现横向滚动；不要写占位内容。

**完成标准:** 新增页面可访问；搜索、分类筛选和复制按钮可用；375px 和桌面宽度布局稳定；npm run typecheck、npm run lint、npm run build 通过。

**输出格式:** 请输出改动计划、修改文件列表、关键实现说明和验证结果。

**验证方式:** 完成后运行 typecheck、lint、build，并说明无法自动验证的部分。


## Bug 修复

**标签:**

- 复现
- 测试
- 回归

**预设内容:**

**角色:** 你是一名严谨的软件工程师，默认采用先复现再修复的 Debug 流程。

**目标:** 修复筛选后列表结果不正确的问题。

**上下文:** 问题出现在 Prompt 列表页。用户输入搜索词后，再切换分类或标签，结果数量与预期不一致。

**限制条件:** 必须先复现；只修改相关组件和工具函数；不要重构样式系统；不要用 any 或关闭类型检查绕过问题。

**完成标准:** 说明复现路径和根因；修复后搜索、分类、标签组合筛选一致；空结果状态正常；类型检查通过。

**输出格式:** 请按：复现、根因、修复、验证、影响范围输出。

**验证方式:** 优先补充测试；如果没有测试框架，请给出明确手动验证步骤。


## Agent 原型

**标签:**

- Agent
- Schema
- 评估

**预设内容:**

**角色:** 你是一名 Agent 架构师和 TypeScript 工程师。

**目标:** 实现一个客户画像 Agent 的最小可用原型。

**上下文:** 目标用户是中国 B2B 安全售前。输入包括客户行业、会议记录、已知需求和我方产品能力。输出要支持会前准备。

**限制条件:** 先实现确定性核心逻辑，不接外部模型；必须区分事实、推断和待验证问题；不要承诺产品不存在能力。

**完成标准:** 定义输入输出 schema；实现核心函数；提供 5 个样例；覆盖缺失字段和冲突信息；输出可复制为 Markdown。

**输出格式:** 请输出数据模型、核心流程、代码文件、样例和评估清单。

**验证方式:** 运行类型检查；如有测试框架，补充并运行单元测试。


## 安全售前自动化

**标签:**

- 零信任
- SASE
- 方案

**预设内容:**

**角色:** 你是一名资深安全售前顾问和 Codex 工程负责人。

**目标:** 新增一个安全售前场景页面，帮助售前生成客户拜访 Brief、问题清单和跟进邮件。

**上下文:** 平台面向中国用户，已有安全售前专区。目标领域包括零信任、SASE、数据安全、XDR、MSS。

**限制条件:** 内容必须符合中国企业客户沟通语境；未知信息标注待确认；不编造客户事实；不做成工具导航站。

**完成标准:** 页面支持搜索、标签筛选、收藏和复制；每个场景包含使用场景、Prompt、输入模板、输出模板和案例；构建通过。

**输出格式:** 请输出新增数据、页面组件、交互说明和验证结果。

**验证方式:** 运行 typecheck、lint、build，并用浏览器检查页面渲染。
