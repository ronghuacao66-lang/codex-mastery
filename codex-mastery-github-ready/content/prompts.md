## 产品官网首屏重构

**类型:** codex

**分类:** 网站开发

**难度:** 进阶

**使用场景:** 已有 Next.js 官网首屏信息层级混乱，需要 Codex 读取代码后重构为高转化、响应式的首屏。

**Prompt:**

请先阅读当前项目的页面结构、组件和样式体系，再重构首页首屏。目标：让用户在 5 秒内理解产品是什么、给谁用、核心价值和下一步动作。约束：保持现有技术栈，不引入新的 UI 框架，不修改无关业务逻辑。Definition of Done：桌面和移动端首屏无文字溢出，CTA 明确，构建通过，并说明你改动了哪些文件。


**输入要求:**

- 产品名称、目标用户、核心卖点
- 当前仓库路径或页面路径
- 需要保留的品牌元素

**输出要求:**

- 修改后的页面和组件
- 响应式适配说明
- 构建或类型检查结果

**最佳实践:**

- 先让 Codex 读代码再改
- 明确不要引入额外依赖
- 把验收标准写成可检查项

**标签:**

- Next.js
- 首页
- 响应式
- DoD
