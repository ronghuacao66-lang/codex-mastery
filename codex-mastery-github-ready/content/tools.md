## ChatGPT

**名称:** ChatGPT

**定位:** 通用 AI 助手，适合方案讨论、知识解释、写作、总结和跨领域思考。

**优势:**

- 开放式对话能力强
- 适合中文写作和方案推演
- 能快速生成结构化草稿

**局限:**

- 默认不直接操作本地仓库
- 工程交付需要人工复制和验证
- 容易在缺少上下文时给泛化建议

**最佳场景:**

- 需求澄清
- 方案讨论
- 文档写作
- 知识解释

**推荐工作流:** 先用 ChatGPT 澄清业务目标和 Prompt，再把明确的工程任务交给 Codex 实现。

**标签:**

- 通用AI
- 写作
- 方案

## Codex

**名称:** Codex

**定位:** 面向软件工程的 coding agent，适合仓库级任务、代码修改、验证和交付。

**优势:**

- 能读取项目上下文
- 能修改文件并运行命令
- 适合端到端实现和 Debug

**局限:**

- 需要清晰目标和约束
- 不适合完全没有验收标准的开放式幻想需求
- 大任务需要拆解

**最佳场景:**

- 网站开发
- 工具开发
- Bug 修复
- 测试补充
- Agent 原型

**推荐工作流:** 用 GCCD 写任务，让 Codex 先读代码、列计划、实施、验证并总结改动。

**标签:**

- Codex
- 开发
- Debug

## Claude

**名称:** Claude

**定位:** 适合长文理解、文档分析、复杂推理和高质量写作的 AI 助手。

**优势:**

- 长上下文处理体验好
- 文档总结和结构化能力强
- 文字风格稳定

**局限:**

- 工程落地仍需要开发环境配合
- 对本地项目操作取决于具体集成方式

**最佳场景:**

- 长文摘要
- 合同或方案审阅
- 知识整理
- 深度写作

**推荐工作流:** 用 Claude 整理资料和形成方案，再用 Codex 把方案产品化为页面、工具或自动化脚本。

**标签:**

- 长文
- 文档
- 写作

## Gemini

**名称:** Gemini

**定位:** Google 生态 AI 助手，适合多模态理解、资料处理和与 Google 工作流结合。

**优势:**

- 多模态和 Google 生态结合好
- 适合资料检索和办公场景
- 可辅助分析图片或文档

**局限:**

- 工程代码落地需要额外工具
- 输出风格需要明确约束

**最佳场景:**

- 资料理解
- 多模态分析
- Google Workspace 场景
- 调研辅助

**推荐工作流:** 用 Gemini 处理多模态资料，再把结构化结论交给 Codex 生成工具或网站模块。

**标签:**

- 多模态
- Google
- 办公

## Cursor

**名称:** Cursor

**定位:** AI 代码编辑器，适合开发者在 IDE 内进行局部代码编写、理解和重构。

**优势:**

- 贴近编辑器工作流
- 局部代码修改快
- 适合边写边问

**局限:**

- 仓库级端到端任务仍需要明确控制范围
- 复杂验证需要开发者主动执行和判断

**最佳场景:**

- 局部重构
- 代码补全
- 解释函数
- 小范围修复

**推荐工作流:** 用 Cursor 做日常编辑和局部理解，用 Codex 承接明确的端到端任务和验证。

**标签:**

- IDE
- 代码
- 编辑器

## Claude Code

**名称:** Claude Code

**定位:** 命令行或开发环境中的编码代理，适合代码库任务和工程协作。

**优势:**

- 适合命令行工程任务
- 长上下文阅读能力强
- 能辅助重构和 Debug

**局限:**

- 具体能力取决于环境配置
- 同样需要清晰边界和验收标准

**最佳场景:**

- 代码阅读
- 重构
- Bug 定位
- 脚本开发

**推荐工作流:** 与 Codex 类似，用明确任务和验收标准驱动；团队可按工具可用性选择。

**标签:**

- Coding Agent
- 命令行
- 开发

## NotebookLM

**名称:** NotebookLM

**定位:** 资料型 AI 工具，适合围绕一组文档进行问答、摘要和学习。

**优势:**

- 围绕资料源工作
- 适合学习和研究
- 能帮助整理文档要点

**局限:**

- 不直接完成代码交付
- 资料质量决定输出质量

**最佳场景:**

- 资料学习
- 研究笔记
- 文档问答
- 课程准备

**推荐工作流:** 用 NotebookLM 理解资料和整理知识，再用 Codex 搭建知识库或学习工具。

**标签:**

- 知识管理
- 学习
- 文档
