## 客户拜访工作流

**负责人:** 销售 / 售前

**触发条件:** 收到客户会议邀请或销售推进重点客户拜访前 24 小时。

**输出结果:** 形成客户背景、拜访目标、问题清单、风险提醒和会后跟进模板。

**实现步骤:**

- 收集客户行业、规模、公开资料、历史沟通和参会角色。
- 用客户画像 Prompt 生成事实、假设和待验证问题。
- 按业务、技术、采购、交付四层生成拜访问题。
- 会后用会议纪要 Prompt 生成行动项和跟进邮件。

**Prompt:** 请为这次客户拜访生成完整 Brief。输入包括客户行业、已知需求、参会人角色、我方产品能力和历史沟通。输出：客户背景、关键假设、拜访目标、分层问题清单、风险提醒、会后跟进邮件。未知信息标注待确认，不要编造。

**检查点:**

- 是否明确本次会议要推进的一个核心目标？
- 是否识别客户决策链和技术影响人？
- 会后行动项是否有负责人和时间？

**标签:**

- 客户拜访
- 售前
- 销售
- 会议

## 售前方案工作流

**负责人:** 售前顾问 / 解决方案架构师

**触发条件:** 客户表达明确需求，需要输出正式方案或汇报材料。

**输出结果:** 形成客户痛点、建设目标、方案架构、实施路径、价值评估和风险边界。

**实现步骤:**

- 整理客户现状和业务痛点，区分事实与推断。
- 映射我方能力到客户痛点，删除无关功能堆砌。
- 生成方案大纲和关键章节，再人工补充产品细节。
- 用方案审查 Prompt 检查价值、风险和边界。

**Prompt:** 请根据客户背景生成安全售前方案。结构：客户现状、痛点诊断、建设目标、总体架构、能力清单、实施步骤、价值评估、风险边界、下一步计划。要求每个能力模块对应一个客户痛点，语言适合中国企业正式汇报。

**检查点:**

- 方案是否先讲客户问题而不是先讲产品？
- 价值是否能对应效率、风险、合规或成本？
- 交付边界和前提假设是否透明？

**标签:**

- 方案
- 售前
- 安全
- 价值

## 竞品分析工作流

**负责人:** 产品市场 / 售前 / 销售

**触发条件:** 客户提到竞品、招标参数包含竞品倾向，或销售需要差异化材料。

**输出结果:** 形成场景化竞品对比、风险提示、我方差异化打法和销售攻防话术。

**实现步骤:**

- 收集竞品资料、客户场景和客户关注点。
- 按部署方式、能力边界、集成难度、服务能力和成本比较。
- 标注未知信息和需要验证的问题。
- 输出销售攻防问答和方案可替换段落。

**Prompt:** 请做场景化竞品分析。输入我方产品、竞品资料、客户行业、客户关注点和项目阶段。输出：竞品定位、能力对比、客户价值差异、我方优势、我方短板、销售攻防话术、验证清单。资料不足必须标注未知。

**检查点:**

- 是否绑定具体客户场景？
- 是否避免编造竞品能力？
- 是否输出销售可直接使用的话术？

**标签:**

- 竞品
- 销售攻防
- 市场
- 产品

## 项目复盘工作流

**负责人:** 项目经理 / 售前 / 交付负责人

**触发条件:** 项目交付、POC、投标或重大客户会议结束后 48 小时内。

**输出结果:** 沉淀目标结果、关键事件、问题根因、经验模板和改进行动。

**实现步骤:**

- 收集项目目标、实际结果、过程记录、问题和数据。
- 按事实、判断、行动三类整理材料。
- 生成复盘报告，避免归因到个人。
- 提炼可复用模板和下次检查清单。

**Prompt:** 请生成项目复盘报告。结构：项目目标、实际结果、关键时间线、做得好的地方、问题和根因、经验沉淀、改进行动、可复用模板。要求基于事实分析系统性原因，每个改进行动包含负责人和时间。

**检查点:**

- 复盘是否有事实和数据？
- 根因是否停留在表面？
- 改进行动是否能被跟踪？

**标签:**

- 复盘
- 项目管理
- 改进
- 沉淀

## 会议纪要工作流

**负责人:** 会议主持人 / 项目成员

**触发条件:** 客户会议、项目周会、需求评审或复盘会结束后。

**输出结果:** 形成可发送的会议纪要、行动项、风险和待确认问题。

**实现步骤:**

- 整理原始会议记录和参会人信息。
- 用纪要 Prompt 提取结论、行动项和风险。
- 人工确认负责人、截止时间和敏感信息。
- 发送跟进邮件，并把行动项同步到项目管理工具。

**Prompt:** 请根据会议记录生成正式会议纪要。输出：会议主题、背景、关键结论、行动项表格、风险、待确认问题和跟进邮件。行动项必须包含负责人、截止时间和状态；不明确的信息标注待确认。

**检查点:**

- 纪要是否区分结论和讨论过程？
- 行动项是否可执行？
- 待确认问题是否被明确列出？

**标签:**

- 会议纪要
- 行动项
- 办公
- 跟进
